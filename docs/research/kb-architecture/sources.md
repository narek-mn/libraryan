# Sources

- [AGENTS.md](https://agents.md/) — open Markdown format for agent instructions; root and nested files, nearest file wins.
- [llms.txt proposal](https://llmstxt.org/) — H1, summary blockquote, H2 link lists, `## Optional` section, `.md` page variants.
- [Diátaxis](https://diataxis.fr/) — tutorial / how-to / reference / explanation split for prose.
- [JSON Schema 2020-12](https://json-schema.org/draft/2020-12) — validation vocabulary used in section 4.
- [RFC 8259](https://www.rfc-editor.org/rfc/rfc8259) (JSON) · [YAML 1.2.2](https://yaml.org/spec/1.2.2/) · [TOML 1.0](https://toml.io/en/v1.0.0) · [CommonMark](https://spec.commonmark.org/)
- [The YAML Norway problem](https://www.bram.us/2022/01/11/yaml-the-norway-problem/) — implicit typing of `NO`, versions and `Null`.
- [RFC 2119](https://www.rfc-editor.org/rfc/rfc2119) — MUST / SHOULD / MAY.
- [MADR](https://adr.github.io/madr/) and [Nygard, *Documenting Architecture Decisions*](https://cognitect.com/blog/2011/11/15/documenting-architecture-decisions) — ADR templates.
- [Liu et al., *Lost in the Middle* (2023)](https://arxiv.org/abs/2307.03172) — models use information at the start and end of long contexts more reliably than the middle.

Format sizes in section 2 were measured on one sample record in this session; chunk-size targets in section 5 are working defaults to tune against your own retrieval evaluation, not published constants.
